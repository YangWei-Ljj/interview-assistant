## 1. 列表 list 和元组 tuple 有什么区别？

列表是可变对象，创建后可以增删改元素；元组是不可变对象，创建后不能修改。
元组因为不可变，可哈希，能作为字典的 key，也更轻量、访问略快。
列表适合元素数量和内容会变化的场景，元组适合表示固定不变的一组数据，如坐标、数据库一行记录。

| 对比项 | 列表 list | 元组 tuple |
| --- | --- | --- |
| 可变性 | 可变 | 不可变 |
| 语法 | 方括号 [] | 圆括号 () |
| 能否做字典 key | 不能 | 能 |
| 典型用途 | 动态集合 | 固定数据 |

## 2. 什么是装饰器？请写一个计时装饰器

装饰器本质是一个接收函数并返回新函数的高阶函数，用于在不修改原函数代码的情况下增强功能，
常用于日志、计时、权限校验、缓存。下面是一个计时装饰器示例：

```
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 耗时 {time.perf_counter() - start:.4f} 秒")
        return result
    return wrapper

@timer
def work():
    time.sleep(0.1)
```

## 3. 什么是 GIL？它对多线程有什么影响？

GIL（全局解释器锁）是 CPython 解释器的一把互斥锁，保证同一时刻只有一个线程执行 Python 字节码。
因此 CPU 密集型任务用多线程无法真正利用多核，适合用多进程绕过 GIL；
而 IO 密集型任务（网络请求、文件读写）在等待 IO 时会释放 GIL，多线程依然能显著提升效率。

## 4. 生成器是什么？有什么好处？

生成器是使用 yield 按需产出值的函数，每次迭代只计算并返回一个值，不会一次性把所有结果放进内存。
好处是节省内存，特别适合处理大文件或海量数据。读取大文件示例：

```
def read_lines(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.strip()
```

## 5. 深拷贝和浅拷贝的区别

浅拷贝只复制最外层容器，内部嵌套对象仍然共享引用；深拷贝会递归复制所有层级，互不影响。
浅拷贝用 copy.copy，深拷贝用 copy.deepcopy。修改嵌套对象时，浅拷贝的结果会联动，深拷贝不会。
